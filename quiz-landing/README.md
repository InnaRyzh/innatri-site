# Лендинг-квиз «Диагностика готовности к марафону»

Статический сайт: `index.html` + `styles.css` + `app.js` + `i18n.js` + `/assets`. Без сборки — заливается в репозиторий GitHub Pages как есть.

## Деплой приёма лидов (Google Apps Script)

1. Создай новую Google Таблицу (в неё будут падать лиды).
2. В таблице: **Расширения → Apps Script**.
3. Удали содержимое `Код.gs` и вставь целиком файл `Code.gs` из этой папки.
4. В начале файла замени:
   - `TELEGRAM_BOT_TOKEN` — токен твоего бота (создаётся у @BotFather);
   - `TELEGRAM_CHAT_ID` — твой chat id (можно узнать у @userinfobot).
5. **Деплой → Новое развёртывание → Тип: Веб-приложение**:
   - «Выполнять от имени»: **От моего имени**;
   - «У кого есть доступ»: **Все** (Anyone);
   - Нажми «Начать развёртывание», разреши доступы.
6. Скопируй **URL веб-приложения** (`https://script.google.com/macros/s/.../exec`).
7. Вставь этот URL в `app.js` — константа `ENDPOINT_URL` в первой строке.

Первая строка с заголовками создастся в таблице автоматически при первом лиде.

После любого изменения `Code.gs` нужно сделать **новое развёртывание** (или обновить существующее через «Управление развёртываниями»), иначе изменения не попадут в веб-приложение.

## Чек-лист: что заменить руками

| Где | Что | На что |
|---|---|---|
| `app.js`, строка 1 | `ENDPOINT_URL` | URL веб-приложения Apps Script (шаг 6 выше) |
| `index.html`, `<script>` в `<head>` | `PIXEL_ID` | ID твоего Meta Pixel (пиксель не грузится, пока стоит плейсхолдер) |
| `Code.gs` | `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | токен бота и chat id |
| `styles.css`, блок `:root` | `--accent: #FF3B30` | уже взят с innatri.com (`--primary`); если нужен другой — меняется в одном месте |

## Как это работает

- Ответы, скоринг и сегмент считаются в `app.js` (баллы и сегмент пользователю не показываются — только зона и тексты).
- Лид отправляется POST-запросом на Apps Script. Если сеть упала — пользователь всё равно видит «Спасибо», а лид сохраняется в localStorage и досылается при следующем открытии страницы.
- Пока `ENDPOINT_URL` не заменён, лиды тоже копятся в localStorage и уйдут при первом открытии страницы с настроенным endpoint.
- Язык RU/UA переключается в правом верхнем углу и запоминается в localStorage. Все тексты — в `i18n.js`.
